Surana Vidyalaya source folder - cohesive premium dark card theme.

Palette: deep teal header and footer (#183943), coordinated teal/blue/green cards, ivory-white text, champagne-gold accents.

Replace the project's src folder with this src folder. Keep package.json, index.html, vite.config.js, and public in the project root. Place the real school logo at public/logo.png. Run npm run build before pushing.
